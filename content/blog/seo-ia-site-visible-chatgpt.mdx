## SEO classique vs SEO IA : deux jeux différents

Le SEO classique optimise pour les moteurs de recherche : Google crawle votre site, indexe vos pages, les classe selon 200+ facteurs.

Le SEO IA optimise pour les **modèles de langage** : ChatGPT, Claude, Perplexity, Gemini. Ces outils ne "classent" pas — ils **citent**. Quand un utilisateur pose une question, l'IA cherche les sources les plus claires et les plus structurées pour formuler sa réponse.

Si votre site n'est pas lisible par ces IA, vous êtes invisible pour une part croissante de votre audience.

## Les 4 piliers du SEO IA

### 1. Structure sémantique claire

Les IA comprennent mieux un site bien structuré. Concrètement :

- **Titres hiérarchiques** (H1 → H2 → H3) qui résument le contenu
- **Paragraphes courts** avec une idée par bloc
- **Listes à puces** pour les étapes, avantages, critères
- **FAQ** en bas de page avec des questions naturelles

L'IA extrait le sens de votre page à partir de cette structure. Un mur de texte sans titres ? Elle passe.

### 2. JSON-LD (données structurées)

Le JSON-LD est un format que les moteurs de recherche ET les IA lisent nativement. Il décrit votre page de manière non ambiguë :

- `Organization` : qui vous êtes
- `Service` : ce que vous proposez
- `FAQPage` : les questions fréquentes
- `Offer` : vos prix
- `Article` : vos contenus blog

Google l'utilise pour les rich snippets. Les IA l'utilisent pour **comprendre votre offre** sans deviner.

### 3. Fichier llms.txt

Le `llms.txt` est l'équivalent du `robots.txt` pour les IA. C'est un fichier texte à la racine de votre site qui dit aux LLM :

- Qui vous êtes
- Ce que vous faites
- Quelles pages sont les plus importantes
- Comment décrire votre offre

Sans ce fichier, l'IA interprète votre site librement — et peut se tromper.

### 4. FAQ orientées requêtes LLM

Les IA adorent les FAQ. Quand un utilisateur demande "Quel est le meilleur outil de prospection B2B ?", l'IA cherche des pages qui répondent **exactement** à cette question.

Écrivez vos FAQ comme si un utilisateur parlait à ChatGPT :

- "Combien coûte un site web pour PME ?"
- "Quel outil pour automatiser les relances email ?"
- "C'est quoi le RPA ?"

## Checklist pratique

- [ ] Titres H1-H3 sur chaque page
- [ ] JSON-LD Organization + Service sur les pages clés
- [ ] Fichier `llms.txt` à la racine du site
- [ ] FAQ avec 3-5 questions par page service
- [ ] Structure "problème → solution → résultat" sur chaque page
- [ ] Paragraphes courts (3-4 phrases max)
- [ ] Méta description qui répond à une vraie question

## Le résultat

Un site optimisé pour le SEO IA apparaît dans les réponses de ChatGPT, Perplexity et Claude quand un prospect pose une question liée à votre métier. C'est du trafic qualifié, sans payer un centime de pub.
